# GuardianAI Demo Script

1. Register a new user.
2. Sign in to the dashboard.
3. Upload `sample-logs/possible-compromise.log`.
4. Open the detected `Possible Account Compromise` incident.
5. Review the AI analysis and recommended response steps.
6. Download the text incident report.

Demo talking point:
GuardianAI is defensive and analyzes simulated log data. It does not attack, exploit, or scan real systems.
